# Project Atlas

Short description
A starter repository scaffold for "Project Atlas". This project groups documentation, App Script source, a web PWA, database artifacts, tests, and assets.

Layout
- docs/ - Architecture, ADRs, ERD, Domain models, Workflows
- appscript/src/ - Services, Repositories, Models, Utilities, UI (Google Apps Script code)
- web/PWA/ - Progressive Web App sources (manifest, service worker, UI)
- database/migrations/ - migration scripts
- database/schema/ - canonical schema files
- tests/ - automated tests
- assets/ - images/other static assets

Getting started
1. Clone or create the repository and run the shell snippet in the repo root to create this scaffold locally if needed.
2. Remove the `.gitkeep` placeholders as you add real files.
3. Fill docs/ with Architecture decisions (ADR), ERD diagrams, and workflows.
4. Add templates/stubs for appscript and web sources as needed.
