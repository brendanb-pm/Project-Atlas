# Weekend Beta Findings

## Promote

- Tenant/brand configuration contract and module registry.
- Module-generated navigation and terminology resolver.
- Firearms specialized UX as a module extension over a canonical Job.
- Atlas Workflow Engine as the common transition boundary for native Kanban and external-board adapters.
- Actionable Command Center composition.

## Backlog

- Durable configuration administration and roles.
- Generic workflow-engine extraction, durable board sync event repository, and native board live refresh/concurrency.
- Real Firearms module stores, photo capture, signature handling, and accessibility/usability testing on target tablets.
- Guided import/onboarding that replaces current Sheets/clasp/deployment tasks.

## Discard / avoid

- Making Asana a source of truth.
- Adding Firearms/Coatings columns to generic core entities.
- Treating quote totals as recognized revenue.
- Exposing setup tooling, JSON, repository settings, or raw IDs to small-shop operators.

## Main before IPM pilot

Do not deploy the current main UI to an IPM tenant. First extract brand/terminology configuration, relocate Cerakote defaults into the Coatings module, and inject storage repositories into operational services. These are contained but material portability blockers.
