# Shop-Floor TV

The 90-inch, 15–25 foot viewing surface should use an Asana Kanban board configured for dark/low-glare presentation: large section headings and work-order IDs; concise cards; and unmistakable NEW, RUSH, BLOCKED, and READY FOR PICKUP cues. Cards show Work Order #, manufacturer/model, item type, requested services, optic footprint, customer first name/company, promised date, assigned operator, priority/blocked signal, and VMOS deep link or QR. They never show addresses, pricing, margin, payment data, or internal IDs.

Recommend **A: a VMOS-owned display shell around a linked/embedded Asana view** first. It preserves Asana's familiar board interaction while VMOS adds authoritative New Work Alert and safe deep links. A standalone VMOS floor board (B) offers stronger control/reliability later but duplicates board rendering and live synchronization work.

When a Work Order reaches RECEIVED, the shell may display an 8–12 second overlay: **NEW WORK RECEIVED**, Work Order #, manufacturer/model, service summary, received time, and optional configurable audible alert. This is a future display integration; it is not implemented or activated here. Document refresh/live-sync assumptions during Asana activation and provide an offline/stale-display indicator.
